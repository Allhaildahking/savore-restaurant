# Savore Restaurant

A premium, cinematic restaurant website concept built with React, TypeScript, Vite, GSAP and ScrollTrigger.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Project notes

- Responsive editorial-style restaurant landing page.
- GSAP entrance animations and ScrollTrigger reveals.
- Current imagery and restaurant details are concept placeholders and should be replaced before launch.
